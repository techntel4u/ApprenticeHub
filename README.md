# Apprentice Hub

Help for City of Wolverhampton College apprentices using e-track (Maytas Hub).

| Tab | Page |
| --- | --- |
| What is e-track? | `index.html` |
| Apprentice Guide | `apprentice-guide.html` |

Plain HTML, CSS and JavaScript with no build step. Styles are in `assets/style.css`, screenshots in `assets/img/`.

Staff guidance lives in the separate assessor hub: https://github.com/techntel4u/Appssupport-hub

## Publishing

Settings → Pages → Deploy from a branch → `main` / root.
